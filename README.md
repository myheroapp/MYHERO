# MyHero - Plataforma de Acompañamiento Físico

MyHero es una plataforma innovadora diseñada para conectar a personas que necesitan acompañamiento físico (para trámites, ocio, asistencia, etc.) con "Heroes" validados y de confianza.

## Estructura del Proyecto

El proyecto está estructurado de la siguiente manera:

- `public/`: Contiene los archivos estáticos públicos que serán servidos al usuario.
  - `index.html`: La landing page principal de la plataforma.
- `src/`: Contiene el código fuente en desarrollo (CSS, JS, Imágenes, etc.).
  - `assets/css/`: Hojas de estilo personalizadas.
  - `assets/js/`: Scripts funcionales de la plataforma.
  - `assets/img/`: Recursos gráficos y multimedia.
- `package.json`: Archivo de configuración de Node.js con scripts y dependencias.

## Cómo empezar

1. Instala las dependencias necesarias:
   ```bash
   npm install
   ```

2. Inicia el servidor de desarrollo local:
   ```bash
   npm start
   ```

El servidor abrirá automáticamente la aplicación en tu navegador predeterminado.
